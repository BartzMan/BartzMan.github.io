Room-by-room duct guide

Follow the air.

Tap a room to see one reason its temperature might feel different.

Balancing

An upstairs room can feel warmer or colder than the rest of the house when airflow is uneven. Ask about balancing the system.

Blocked return

Air needs a route back to the system. Check from the room that furniture and rugs leave the return grille clear.

Duct leak

A room far from the system may receive less air if a duct is disconnected or leaking. An HVAC technician can assess the run.

Filter

A clogged filter can restrict airflow across the whole house. If it is accessible and due for a change, use the type listed for the system.

Mohawk Valley homeowner guide

Before the hard frost.

Start at the thermostat

When a cool day arrives, select heat and note whether the room starts warming.

Check the filter

If the filter is due for a change, use the type and size listed for your system.

Clear the grilles

Move rugs and furniture away from supply and return grilles.

Write down changes

Note which rooms stay cold and whether the system starts and stops unusually often. Share what you notice when you call.
